# Grand Jodus 宜蘭礁溪會館：服務利潤鏈（Service-Profit Chain）模擬遊戲

本專案是「服務利潤鏈（Service-Profit Chain, SPC）」的教學沙盤。v2 版以 Heskett 等人（1994）提出的 SPC 原型為骨架，並依 Hogreve 等人（2017）的後設分析與 Hogreve 等人（2022）的修正觀點，重新設計因果結構。遊戲要傳達的核心訊息是：**服務利潤鏈追求的是「最適化」，而不是「最大化」。**

本專案為單一網頁檔案（`index.html`），不需資料庫或後端伺服器，可直接以 GitHub Pages 發布，學員用手機、平板或筆電瀏覽器即可遊玩。

> ⚠️ 模型為教學用簡化版本，參數經過校準以呈現文獻的方向性發現，數值不代表真實產業資料。

## 🏨 情境背景

坐落於宜蘭礁溪美人湯泉景區的 **Grand Jodus 礁溪旗艦會館**，原以細緻的在地款待文化聞名。跨國投資基金入主後，新管理層為了追求短期季度獲利而極端控本：解雇資深領班、壓低基層薪資、取消服務培訓、收回第一線處置授權。

第 0 季（基準線）的營運狀況：

- 基層員工年流動率：**112.4%**
- 顧客滿意度（CS）：**42.1 / 100**
- 單季營業損益：**NT$ −2,485,000**
- 顧客回頭率：**17.7%**

您受聘接掌礁溪會館，必須在四個季度內重新配置人力資源投資，帶領團隊走出「失敗循環（cycle of failure）」，啟動「成功循環（cycle of success）」。

## ⚙️ 決策變數與預算上限

每季配置三根滑桿（0～100）：

| 決策變數 | 意涵 | 模型中的效果 |
|---|---|---|
| **薪資福利（C）** | 基層薪酬與勞動條件 | 提升員工滿意、福祉與留任，但邊際遞減；**調降薪資**會觸發損失規避，滿意度受 1.8 倍懲罰 |
| **教育訓練（T）** | 服務 SOP、客訴處理與款待訓練 | 累積為**技能存量**，一半效果延到下一季才發酵；技能存量是授權發揮正面效果的前提 |
| **第一線授權（E）** | 現場補救與驚喜預算 | 技能存量 < 40 時造成濫用損失（Q1 最佳補救也需技能存量 ≥ 40）；E > 70 時出現「甜心交易（sweethearting）」成本，顧客也更容易忠於個別員工 |

**董事會預算上限**：每季「薪資＋訓練」支出（C × 8 萬 ＋ T × 5 萬）不得超過上限，起始為 NT$ 900 萬。上季若虧損擴大，下季上限縮減 5%（失敗循環）；若獲利，下季上限提高 5%（成功循環）。超過上限時無法提交策略。

## 🔗 模型因果結構與文獻對應

```
內部服務品質（薪資、技能存量）
   ├─→ 員工滿意 ─┬─→ 員工留任 ─→ 營收（直接效果）
   │             └─→ 員工生產力
   ├─→ 員工福祉 ─────→ 員工留任、員工生產力
   └─→ 員工生產力（直接效果）
員工生產力＋技能存量＋授權 ─→ 外部服務品質 ─→ 顧客滿意 ─→ 顧客忠誠 ─→ 營收
                                          （員工滿意 → 顧客滿意：弱的直接效果）
顧客滿意（上季）─→ 員工滿意（回饋）
本季損益 ─→ 下季預算上限（回饋）
```

| 規則 | 文獻依據 |
|---|---|
| 新增**外部服務品質**節點；員工滿意對顧客滿意只有弱的直接效果 | Hogreve et al.（2017）：內部服務品質直接影響外部服務品質；滿意鏡像效果較弱 |
| 內部服務品質（技能）直接影響**員工生產力** | Hogreve et al.（2017）：員工滿意只中介內部服務品質對生產力效果的一部分 |
| 訓練轉為**技能存量**，有一半效果延到下一季 | 時間落差；Hogreve et al.（2022）呼籲縱貫研究 |
| 新增**員工福祉**，受人力缺口造成的工作負荷影響 | Hogreve et al.（2022）修正方向②：福祉 |
| 員工滿意明顯高於外部服務品質時，對顧客忠誠產生**負向效果**（組織內向） | Hogreve et al.（2017）：員工滿意對顧客忠誠的直接效果為負 |
| 顧客忠誠為 **S 型曲線**（背離區、無差異區、情感區），並受員工生產力直接影響 | Heskett et al.（1994）；Hogreve et al.（2017） |
| 營收對忠誠**邊際遞減**；外部服務品質超過 75 後**品質維持成本**加速上升 | 品質報酬觀點；Hogreve et al.（2017）：外部服務品質對獲利的殘差效果為負 |
| **員工留任**直接提升營收 | Hogreve et al.（2017） |
| 授權過高出現甜心交易；流動率高時，**員工帶走忠於個人的顧客** | Hogreve et al.（2022）修正方向③：忠誠對象 |
| 上季顧客滿意**回饋**本季員工滿意；損益回饋下季預算 | Hogreve et al.（2022）修正方向⑤：回饋迴路；Heskett et al.（1994）：失敗循環 |
| 第四季 **AI 導入**事件 | Hogreve et al.（2022）：在數位轉型下重新想像 SPC |

## ⚡ 關鍵時刻事件

各季事件固定出現，方便各組公平比較：

1. **Q1 VVIP 紅酒污漬危機**：最佳補救方案需要「授權 ≥ 50 且技能存量 ≥ 40」才能解鎖，與盲目授權門檻一致。因為訓練效果有時間落差，第一季訓練需達 70 以上才來得及。
2. **Q2 前線過勞潮**（情境文字依當時流動率切換）：加班補貼（A，當季損益較好）、關閉 15% 客房以降低負荷、改善福祉（B，營收減少約 180 萬，但福祉與留任較好）、精神動員（C）。
3. **Q3 競爭對手挖角戰**（情境文字依技能存量切換）：永久加薪 12%＋留任獎金（A，實質待遇與薪資成本同步提高，之後各季更容易留任，但人資支出永久增加 12%）、升遷與證照（B，技能存量 +5，熟客較不會跟著員工流失）、不予跟進（C，技能存量 −10，骨幹與熟客一起流失）。
4. **Q4 AI 導入**：全面以 AI 取代部分前線人力（A，短期省成本，但帶來科技壓力與疏離）、AI 支援員工並保留真人選項（B）、暫不導入（C）。

## 🏆 評級標準

第四季結束時，董事會依**累計損益**、**期末員工流動率**與**期末顧客滿意度**綜合評定：

- 🏆 **S 級**：累計損益 > NT$ 300 萬、流動率 < 45%、顧客滿意 > 78
- 🌟 **A 級**：累計損益 > NT$ −300 萬、顧客滿意 > 70、流動率 < 60%
- 💼 **B 級**：顧客滿意 ≥ 55 且流動率 < 90%
- 🚨 **F 級**：其他

> 💡 **全部調到 100 可以嗎？** 不行。薪資與訓練同時拉滿會超過預算上限而無法提交；即使預算允許，品質維持成本與甜心交易成本也會讓獲利轉為虧損。
>
> 💡 **獲利最高就是最好嗎？** 不一定。壓低薪資的策略可能在四季內累積最高利潤，但流動率與顧客滿意不達標，只能拿到 B 級。這正是課堂討論「利潤最大化」與「服務利潤鏈成功循環」差異的好素材。

## 🎮 遊玩步驟

1. 開啟遊戲網址，閱讀礁溪會館的危機背景，點擊「接受委任，即刻入主」。
2. 調整薪資（C）、訓練（T）、授權（E）三根滑桿，確認本季人資支出未超過預算上限。
3. 提交策略後處理當季的關鍵時刻事件。
4. 閱讀季度結算：情境回報、「本季模型訊號」與學術點評。
5. 第四季結束後，截圖「四季策略軌跡與數據對比覆盤表」，作為課堂討論與作業依據。

## 🎓 MBA 課堂引導與覆盤討論

### 建議操作（非同步課程：兩回合設計）

1. **第一回合（看導讀影片前）**：憑直覺玩一次，只繳交第一次的結果，捕捉「CEO 的直覺」。
2. **觀看導讀影片**。
3. **第二回合（看影片後）**：刻意運用文獻概念再玩一次。
4. **繳交 Teams 討論區**：兩張期末截圖，並各用一句話回答：
   - 兩回合的策略差在哪裡？為什麼改？
   - 遊戲中哪一個機制最能對應 Hogreve et al.（2022）的哪一個修正方向？
   - 遊戲模型還漏掉了文獻中的哪一個機制？如果你是設計者，會怎麼改？
   - 最後回應一位同學。

### 覆盤問題

| 討論問題 | 對應文獻 |
|---|---|
| Q1 加薪加訓時，當季財報如何？紅酒危機的最佳方案為何鎖住？ | 時間落差；技能存量；人資管理系統 |
| Q2 選 A 和選 B 的組別，當季損益與期末流動率各有何不同？ | 短期財務 vs. 福祉的長期效果 |
| Q3 選 A（加薪）和選 B（升遷與證照）的組別，各換到了什麼？ | 留任、技能與成本的取捨；原典「最適留任率很少是 100%」 |
| 只加薪不訓練的組別，為什麼員工很滿意，顧客忠誠卻上不去？ | 組織內向：員工滿意對顧客忠誠的負向效果（Hogreve et al., 2017） |
| 授權拉到 80 以上發生了什麼事？ | 人資管理系統的綜效與抵銷；甜心交易與忠誠對象（Hogreve et al., 2022） |
| Q2 選 B（降低負荷）的組別，福祉與流動率有何變化？ | 修正方向②：福祉 |
| Q3 選 C 的組別，為什麼顧客也一起流失？ | 修正方向③：顧客忠於員工 |
| 獲利最高的組別為什麼不是 S 級？ | 最適化而非最大化；員工留任對營收的直接效果 |
| Q4 選 A（全面取代）的組別，本季損益與期末指標如何？ | 重新想像 SPC：支援型 AI vs. 體驗型 AI、科技壓力與疏離 |
